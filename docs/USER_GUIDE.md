## 1. 日常启动方式

- **Windows 用户**：双击仓库根目录下的 `打开团队协作面板.cmd`（或 `Start-Roundtable.cmd`，可右键“发送到 -> 桌面快捷方式”），后台将无弹窗静默检查并拉起本地服务，随后自动打开 `http://127.0.0.1:8765/`。
- **macOS / Linux 用户**：在终端执行 `./Start-Roundtable.sh`。
- **Antigravity 内置自动随启**：将 `codex-team` 配置进 `mcp_config.json` 后，每次打开 Antigravity 时后台服务会自动随启，浏览器直接访问书签 `http://127.0.0.1:8765/` 即可。

## 2. 界面语言与主题切换

- **中英双语切换**：点击顶栏右侧的 **`EN` / `中文`** 按钮即可实时切换工作台语言，当前草稿与运行中的任务状态零丢失。
- **深浅色主题切换**：点击太阳/月亮图标即可在「静谧深色」与「纸感浅色」阅读模式间切换。

## 3. 四种协作组织方式

1. **🪑 群聊圆桌议事厅（`roundtable`）**
   - 勾选 2 位及以上跨引擎专家入席，指定 1 位主持人并选择讨论轮数（1–3 轮）。默认开启「首轮直接并行开跑（真盲评隔离）」，多轮交叉 `@队友` 质询核验并可选开启「匿名互评 + Borda 计票」，最后由主持人汇总定稿。
2. **🎖️ 总管自动点将台（`chief_dispatch`）**
   - 选定 1 位坐镇主帅先勘察当前项目结构与团队花名册，按需动态抽调 `1–12` 名精兵编排串行/并行/审查步骤并终审签发。
3. **🧱 多轨搭积木工坊（`custom_dag`）**
   - 自由增删第 `1..N` 阶段与同阶段并行工位，支持插入独立审查关卡（最多 2 轮自动退回修复，超限转交人工裁决）。
4. **⚡ 专家一对一专办（`single_member`）**
   - 面对面直连单名 Codex 或 Antigravity 专家极速交付，支持原会话续聊追问。

## 4. 三档沙箱与跨目录权限控制（v5.6.0）

点击顶栏右侧权限胶囊（`🔒 只读` / `✏️ 可写` / `⚠️ 完全访问`）即可打开 **「沙箱与目录权限中心」**：

- **🔒 只读模式 (`read-only`)**：仅允许阅读与审查文件，禁止任何写入操作。
- **✏️ 项目目录可写 (`workspace-write`)**：日常写代码、科研绘图与运行 R/Python 脚本推荐档；可在下方 **「附加跨盘/外部授权目录 (`--add-dir`)」** 中粘贴或通过系统选目录弹窗添加最多 8 个外部文件夹（无需放开整机权限即可跨盘读写）。
- **⚠️ 完全访问 (`danger-full-access`)**：默认安全锁定；确有需要时点击「解锁完全访问（需二次确认）」勾选风险提示后解锁，用完可随时点击「立即重新锁定并回收」一键降级回安全可写档。
- **圆桌单席独立权限**：在可写或完全访问圆桌中，可点击每个已选参会专家胶囊上的 `🔒 / ✏️ / ⚠️` 图标单独设置该席位权限（如审稿官保持只读、绘图/统计官可写）。
